# Practice Lock File Workflows and Dependency Resolution

## Task Brief
Demonstrate lock file updates, transitive dependency inspection, and conflict resolution in toolkit.

## Scenario
Your team discovered a transitive dependency issue. Inspect the dependency tree, update lock files, and document findings.

## Deliverables
- Dependency tree analysis document
- Updated lock file with resolved conflicts
- Dependency resolution notes

## Success Criteria
- Transitive dependencies identified and documented
- Lock file successfully regenerated
- Conflict resolution approach explained
