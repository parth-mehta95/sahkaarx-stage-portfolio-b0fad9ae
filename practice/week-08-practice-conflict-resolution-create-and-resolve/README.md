# Practice Conflict Resolution: Create and Resolve Merge Conflicts

## Task Brief
Create conflicting branches in toolkit repo; practice detecting and resolving merge conflicts using Git tools and strategies.

## Scenario
Your team is integrating multiple processor implementations. Create conflicting branches and practice resolving merge conflicts safely.

## Deliverables
- Two feature branches with conflicting changes
- Resolved main branch after merge

## Success Criteria
- Conflicts detected and marked correctly
- Manual resolution preserves both features
