# Practice: Add GitHub Actions Build Pipeline

## Task Brief
Configure GitHub Actions workflow for automated testing, linting, and build validation on every commit.

## Scenario
Your team requires CI/CD automation. Set up GitHub Actions to validate code quality and run tests.

## Deliverables
- GitHub Actions workflow file (.github/workflows/build.yml)
- Build pipeline with test and lint stages
- Pipeline documentation

## Success Criteria
- Workflow triggers on push and pull requests
- All tests pass in CI environment
- Linting checks pass before merge
