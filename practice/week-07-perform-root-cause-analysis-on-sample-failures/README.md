# Perform Root Cause Analysis on Sample Failures

## Task Brief
Analyze sample API failures using stack traces and logging; document root causes and remediation steps.

## Scenario
Your ops team reports three production failures. Perform root cause analysis using logs and stack traces to identify fixes.

## Deliverables
- RCA document
- Remediation steps
- Test cases

## Success Criteria
- Root causes identified
- Fixes implemented
- Tests pass
