## Task Brief
Apply flexible version constraints to toolkit dependencies; document rationale for constraint choices and demonstrate update safety.

## Scenario
Your team needs clear version constraint policies. Document and apply semantic versioning constraints to toolkit dependencies.

## Deliverables

- Updated pyproject.toml with constraints
- Constraint rationale guide

## Success Criteria
- Constraints follow semantic versioning
- Documentation explains each constraint choice
- Poetry respects constraints during updates
