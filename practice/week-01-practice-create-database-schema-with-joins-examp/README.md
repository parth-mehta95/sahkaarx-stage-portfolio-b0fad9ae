# Practice: Create Database Schema with Joins Example

## Task Brief
Design a sample database schema demonstrating join operations and add query examples to the toolkit documentation.

## Scenario
Product team wants toolkit to include database patterns. Add schema examples and join query demonstrations.

## Deliverables
- Database schema diagram or SQL file
- Join query examples with documentation
- Integration test for join operations

## Success Criteria
- Schema includes at least 2 related tables
- Examples show INNER and LEFT joins
- Queries execute without errors
