# Add Breakpoint-Friendly Logging Hooks

## Task Brief
Integrate logging hooks that support breakpoint inspection; enable step-through debugging of transaction flow.

## Scenario
Your team needs better debugging visibility. Add logging hooks that work with breakpoints for transaction inspection.

## Deliverables
- DebugLogger with breakpoint hooks
- Transaction flow logging
- Breakpoint-friendly output format

## Success Criteria
- Logs capture transaction state at key points
- Breakpoints pause execution cleanly
- Output is readable during step-through
