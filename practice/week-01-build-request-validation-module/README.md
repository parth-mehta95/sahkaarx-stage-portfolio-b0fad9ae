# Build Request Validation Module

## Task Brief
Implement schema-based request validation with error responses, demonstrating API contract design and validation patterns.

## Scenario
Your API team requires a validation module that validates incoming requests against defined schemas and returns structured errors.

## Deliverables
- RequestValidator class
- ValidationSchema interface
- Error response handler

## Success Criteria
- Validator accepts schema and request objects
- Returns structured error messages
- Handles multiple validation rules
