# Practice Git Branching and Feature Workflow

## Task Brief
Create feature branch, make commits, and practice branch switching for collaborative development.

## Scenario
Your team uses feature branches for all work. Practice creating a branch for the array-storage feature, making commits, and switching between branches.

## Deliverables
- Feature branch with 3+ commits
- Branch history showing clear workflow

## Success Criteria
- Feature branch created and checked out
- Multiple commits on feature branch
