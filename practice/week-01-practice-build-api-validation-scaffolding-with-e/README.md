# Practice: Build API Validation Scaffolding with Example Validators

## Task Brief
Create API validation module with example endpoint validators and request schema enforcement.

## Scenario
Your toolkit needs API validation. Build validators for request schemas and error handling.

## Deliverables
- API validation module with 3 validators
- Example Flask/FastAPI endpoint with validation
- Unit tests for validators using mocks

## Success Criteria
- Validators reject invalid requests
- Valid requests pass through
- Tests cover success and failure paths
