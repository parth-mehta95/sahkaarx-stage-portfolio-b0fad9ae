# Refactor Toolkit to Use Poetry and pyproject.toml

## Task Brief
Convert toolkit from pip/requirements.txt to Poetry; create pyproject.toml with proper metadata and dependency groups.

## Scenario
Your team wants modern dependency management. Migrate the toolkit from pip to Poetry with pyproject.toml configuration.

## Deliverables
- pyproject.toml with Poetry config
- poetry.lock file generated
- Migration guide in README

## Success Criteria
- Poetry install works cleanly
- All dependencies resolve correctly
- Dev dependencies separated from production
