# Practice pip Installation and Dependency Declaration

## Task Brief
Install packages using pip, create requirements.txt, and verify dependency resolution.

## Scenario
Your toolkit needs core dependencies. Install packages and document them in requirements.txt.

## Deliverables
- requirements.txt with pinned versions
- Virtual environment setup script
- Dependency verification log

## Success Criteria
- All packages install cleanly
- Versions are pinned correctly
- Script reproduces environment
