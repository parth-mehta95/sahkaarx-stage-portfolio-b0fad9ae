# Practice: Configure GitHub Actions CI/CD Pipeline

## Task Brief
Set up automated testing, linting, and build validation workflow triggered on every commit and PR.

## Scenario
Your team needs automated quality gates. Configure GitHub Actions to run tests and linting on every push.

## Deliverables
- GitHub Actions workflow file
- CI/CD pipeline documentation
- Build status badge

## Success Criteria
- Workflow runs on push and PR
- Tests execute automatically
- Linting checks pass
