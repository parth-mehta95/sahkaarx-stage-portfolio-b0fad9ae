# Add Exception Handling to Toolkit Components

## Task Brief
Extend your toolkit with custom exception classes and handle file-not-found and invalid-input errors gracefully.

## Scenario
Your team needs robust error handling in the toolkit. Add custom exceptions and defensive checks to DataProcessor, Logger, and Validator.

## Deliverables
- Custom exception classes in toolkit
- Updated components with try-catch blocks

## Success Criteria
- File-not-found errors handled gracefully
- Invalid input rejected with clear messages
