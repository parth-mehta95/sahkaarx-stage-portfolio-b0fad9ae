# Practice: Update and Audit Toolkit Dependencies

Safely update all toolkit dependencies, run vulnerability scans, and document security audit results with lock files.

## Scenario
Security team requires dependency audit. Update all packages, run CVE scans, verify lock file integrity.

## Deliverables
- Updated uv.lock with all dependencies
- Vulnerability scan report
- Security audit documentation

## Success Criteria
- All dependencies updated safely
- Zero critical CVEs reported
- Lock file validates and builds
